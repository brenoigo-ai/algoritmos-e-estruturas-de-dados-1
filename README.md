## 📂 Estrutura do Repositório

O repositório está organizado em módulos para facilitar a navegação. Cada pasta de resolução acompanha o arquivo PDF ou imagem com o enunciado original da questão para contexto. Todos os algoritmos foram desenvolvidos em **Python 3** utilizando o paradigma de programação estruturada.

```text
📦 algoritmos-e-estruturas-de-dados-1
 ┣ 📂 listas (Estruturas base da linguagem)
 ┃ ┣ 📂 lista_01 (Cálculos básicos, operadores matemáticos e variáveis)
 ┃ ┣ 📂 lista_02 (Estruturas de decisão e condicionais: if, elif, else)
 ┃ ┣ 📂 lista_03 (Estruturas de repetição: for, while, validações e séries matemáticas)
 ┃ ┗ 📂 lista_04 (Modularização, funções com retorno, procedimentos e parâmetros)
 ┣ 📂 atividades (Aplicações práticas e lúdicas)
 ┃ ┣ 📂 dungeon (Minijogo em terminal com mecânicas de RNG e controle de estado)
 ┃ ┗ 📂 investimentos (Simulador financeiro com regra 50/30/20 e juros compostos)
 ┗ 📂 avaliacoes (Projetos avaliativos)
   ┗ 📂 pesquisa_votos (Sistema de Pesquisa Eleitoral com tabulação demográfica)

🛠️ Características do Código
Menus Interativos: Todos os scripts possuem um menu principal em loop contínuo, permitindo testar várias questões na mesma execução.

Validação de Dados: Implementação rigorosa de try/except para impedir quebras por entradas de tipos inválidos (ex: digitar letras em campos numéricos).

Tratamento de Fronteiras: Lógica ajustada matematicamente para casos nulos, negativos e classes de equivalência.

Padrão Regional: Funções customizadas para aceitar entradas com vírgula e exibir saídas financeiras no formato PT-BR (ex: R$ 2.500,00).

🚀 Como executar
Para testar os códigos localmente, você precisa ter o Python 3 instalado na sua máquina.

Clone este repositório:

Bash
git clone https://github.com/brenoigo-ai/algoritmos-e-estruturas-de-dados-1.git
Navegue até a pasta desejada e execute o arquivo correspondente. Por exemplo:

Bash
cd algoritmos-e-estruturas-de-dados-1/avaliacoes/pesquisa_votos/
python3 avaliacao_pratica_pesquisa_votos.py
